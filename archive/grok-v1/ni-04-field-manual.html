06 / SYSTEM VALIDATION

Design test

顶栏 Signal / Anno / Gray 是活测试。关掉强调色和微图形后，网格与字体仍应成立。

[Invented]
  • 01 · Signal off去掉安全橙。构图还像工程文件吗？
  • 02 · Anno off去掉微图形。字号、间距、对齐是否仍能独立成立？
  • 03 · Purpose每个装饰能否解释操作或信息用途？只为好看的，删。
  • 04 · GrayscaleGray 模式下系统是否仍可读、可部署？
  • 05 · Field object能否印在铭牌、纸箱、机台界面或工作夹克上？

Structure first / Signal second / Decoration last

If it looks decorated, remove something. If it looks engineered, keep going.
