Lockup — mark + wordmark framed by two mono metadata bars; the nameplate format for brands, units and documents.

```jsx
<Lockup word="Orbital" sub="Sys-01 · Continuous build" top={["Status: Active","U.S.A.","Field lab"]} bottom={["Unit NI-04","Rev 1.4","WED 02 SEP 26"]} />
```

Both bars are required for the format to read as a lockup; drop one only on very narrow prints.
