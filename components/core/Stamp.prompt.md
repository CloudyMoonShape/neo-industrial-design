Status stamp — a mono uppercase label in a 1px box; the signature "data stamp" of the system.

```jsx
<Stamp tone="solid">Target locked</Stamp>
<Stamp>Status: Field testing</Stamp>
<Stamp tone="online">Link stable</Stamp>
```

- One `solid` stamp per view at most; use `ghost` for the rest.
- Copy pattern: `KEY: VALUE` or `KEY / VALUE` ("STATUS: ACTIVE", "DATUM / WGS 84").
